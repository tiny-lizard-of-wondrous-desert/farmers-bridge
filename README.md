# farmers-bridge

Welcome to Farmer's Bridge! This is a card game I coded up to play with friends & family.

My family in the Netherlands called it "Farmer's Bridge", but if you have another name for it, please feel free to share!


## How do I play?
### How many players do I need?
The game can have anywhere from 2-51 players technically, but too few people means one is always restricted in calls and too many people makes it extremely unfortunate to go first for bidding.

It is most fun playing with 3-6 people.
